# 🏠 ניהול הבית

אפליקציה פרטית לניהול בית משותף. היא עובדת בטלפון כמו אפליקציה רגילה (PWA), בעברית, ומסתנכרנת בזמן אמת בין שניכם.

| | פיצ'ר | מה הוא עושה |
|---|---|---|
| 🛒 | **רשימת קניות משותפת** | הוספה מהירה ("2 חלב"), מיון לפי מחלקות בסופר, השלמה אוטומטית ממה שקניתם בעבר, סימון "בעגלה", ועבודה גם בלי קליטה. "סיימתי קנייה" מכניס את הקנייה להתחשבנות. |
| 🏪 | **השוואת סלים** | מחירי שופרסל, רמי לוי, אושר עד, קרפור וטיב טעם בבאר שבע, מקובצי חוק שקיפות המחירים. המחירים מתעדכנים כל בוקר. לכל פריט נבחר בכל סניף המוצר הזול מאותו סוג וגודל ("ביצים" הן אריזת 12 L, לא סלט ביצים), ירקות לפי ק"ג. שורה לכל רשת, והסכום הוא בדיוק סכום השורות. אפשר לקשר פריט למוצר מסוים. |
| 💸 | **התחשבנות (כמו Splitwise)** | הוצאות משותפות עם חלוקה שווה, באחוזים, בסכומים, או "הכל על". מאזן "יתרה לטובת", סגירת חשבון, והיסטוריה עם סינון. |
| 💡 | **חשבונות ותשלומים קבועים** | ארנונה, חשמל, מים, שכירות ומנויים, כולל חשבונות דו-חודשיים. תזכורות לפני כל תשלום, "שולם" שמתחלק ביניכם אוטומטית, והוראות קבע שנרשמות לבד. |
| 🧹 | **מטלות ותורנות** | מטלות חוזרות, עם תורנות לסירוגין, אחריות קבועה, או "מי שפנוי". אפשר לראות מה צריך לעשות היום ומי עשה כמה החודש. |
| 🔔 | **התראות לטלפון** | תזכורות לחשבונות ולמטלות, הוצאה או העברה שבן/בת הזוג רשמו, וסיכום שבועי, גם כשהאפליקציה סגורה. כל טלפון מפעיל בנפרד, וכל סוג כבוי עד שבוחרים בו. לא שולחות בלילה. |
| 📊 | **תובנות** | השוואת קצב ההוצאות לחודש שעבר, חשבון שקפץ, מוצרים שהתייקרו, "כנראה נגמר לכם…", ומגמה של 6 חודשים. |

## מבנה

```
web/        האפליקציה: React, TypeScript, Vite, PWA. כל פיצ'ר בתיקייה משלו ב-src/features
supabase/   מבנה מסד הנתונים (migrations) והרשאות לכל משק בית (RLS)
ingest/     טעינת מחירי הסופרים (Python), רצה כל יום ב-GitHub Actions
docs/       מדריך הקמה
```

הכל רץ על שירותים בחינם:
- **Supabase**: מסד נתונים, התחברות וזמן אמת.
- **Cloudflare Pages**: אחסון האתר.
- **GitHub Actions**: מחירים, בדיקות ו-migrations.

## מתחילים

👈 **[docs/setup.md](docs/setup.md)**: הקמה מלאה בכ-30 דקות.

```bash
cd web && pnpm install && cp .env.example .env.local && pnpm dev
```

**דמו בלי שום הקמה:** הפקודה `pnpm dev:demo` (או `pnpm build:demo`) מריצה את האפליקציה כולה בדפדפן, על נתוני דוגמה וללא Supabase (הקוד ב-`web/src/demo`). בפס העליון אפשר לעבור בין הטלפון של מיכאל לטלפון של יהלי, ולאפס את הנתונים.

## להוסיף פיצ'ר

כל פיצ'ר הוא תיקייה עם `index.ts` שנרשם בשורה אחת ב-`web/src/app/features.ts`. משם הניווט, הדפים והכרטיסים במסך הבית נבנים לבד. ההוראות המלאות, כולל קובץ migration ובדיקות, נמצאות ב-[CLAUDE.md](CLAUDE.md).

רעיונות להמשך:
- מזווה ותוקף מוצרים
- תכנון ארוחות שמעביר מצרכים לרשימה
- תזכורות אחזקה
- קבלות ותעודות אחריות
- יעדי חיסכון
- מבצעים בהשוואת הסלים: קובצי PromoFull של הרשתות, כולל מבצעי "2 ב-X" ומבצעים לחברי מועדון (היום ההשוואה לפי מחירי מדף)
- סריקת ברקוד

## קרדיט

הורדת קובצי המחירים נעשית עם [israeli-supermarket-scarpers](https://github.com/OpenIsraeliSupermarkets/israeli-supermarket-scarpers) של Sefi Erlich. הספרייה ברישיון לשימוש לא-מסחרי, והשימוש כאן הוא אישי ולא מסחרי. לא נעשו בה שינויים.
